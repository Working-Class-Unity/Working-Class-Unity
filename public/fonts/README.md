# WCU web fonts

These WOFF2 files were converted without subsetting from the source font files supplied by Working
Class Unity:

- `acumin-pro-regular.woff2` from `Acumin-RPro.otf`
- `acumin-pro-bold.woff2` from `Acumin-BdPro.otf`
- `akira-jimbo-regular.woff2` from `Akira Jimbo.ttf`

Harpreet Chima confirmed WCU's right to self-host the supplied fonts on 2026-09-02 (redesign Decision
Log VIS-2). The supplied asset package did not include a separate license or purchase record, so retain
that authorization as production provenance. The original source files remain outside this repository
in the redesign source-asset archive.

Acumin Pro is the body and UI face. Akira Jimbo is restricted to short identity, campaign, and
editorial declarations. System fallbacks remain required for glyphs the supplied files do not cover,
including Punjabi text.
